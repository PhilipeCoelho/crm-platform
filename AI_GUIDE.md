# 🤖 Sistema de IA - Guia Completo

## 📋 **Visão Geral**

O CRM Pro agora possui um **Assistente de IA completo** integrado, com suporte para **3 provedores de IA**:
- ✅ **OpenAI** (GPT-4, GPT-3.5)
- ✅ **Anthropic Claude** (Claude 3.5 Sonnet, Opus)
- ✅ **Google Gemini** (Gemini 1.5 Pro, Flash)

---

## 🚀 **Como Configurar**

### **1. Obter API Key**

Escolha um provedor e obtenha sua API key:

#### **OpenAI**
1. Acesse: https://platform.openai.com/api-keys
2. Faça login ou crie uma conta
3. Clique em "Create new secret key"
4. Copie a chave (começa com `sk-...`)

#### **Anthropic Claude**
1. Acesse: https://console.anthropic.com/settings/keys
2. Faça login ou crie uma conta
3. Clique em "Create Key"
4. Copie a chave

#### **Google Gemini**
1. Acesse: https://makersuite.google.com/app/apikey
2. Faça login com sua conta Google
3. Clique em "Create API Key"
4. Copie a chave

### **2. Configurar no CRM**

1. Clique no botão flutuante de IA (✨) no canto inferior direito
2. Se não configurado, aparecerá a tela de configuração
3. Selecione o provedor desejado
4. (Opcional) Escolha o modelo específico
5. Cole sua API key
6. Clique em "Salvar Configuração"

## 📊 **Análises Automáticas**

### **Módulo Insights**
A IA pode analisar automaticamente seus relatórios:

1. Crie um relatório no módulo Insights
2. Clique em "Analisar com IA" (em breve)
3. Receba insights automáticos sobre:
   - Tendências identificadas
   - Anomalias nos dados
   - Recomendações de ações
   - Previsões futuras

### **Análise de Deals**
- Identifica deals com maior probabilidade de fechar
- Sugere próximos passos para cada negócio
- Detecta deals estagnados que precisam de atenção

### **Análise de Atividades**
- Identifica padrões de produtividade
- Sugere otimizações de agenda
- Detecta gargalos no processo de vendas

## 🔒 **Segurança e Privacidade**

### **Armazenamento Local**
- Sua API key é armazenada **apenas no seu navegador**
- Nunca é enviada para nossos servidores
- Você pode removê-la a qualquer momento

### **Comunicação Direta**
- O CRM se comunica **diretamente** com o provedor de IA escolhido
- Não há intermediários
- Seus dados seguem as políticas de privacidade do provedor

### **Dados Enviados**
A IA recebe apenas:
- Dados agregados e anônimos para análises
- Contexto necessário para responder suas perguntas
- Nunca envia informações sensíveis sem sua permissão

## 🐛 **Solução de Problemas**

### **"IA não configurada"**
- Verifique se você inseriu uma API key válida
- Certifique-se de que a chave está ativa no provedor

### **"Erro ao enviar mensagem"**
- Verifique sua conexão com a internet
- Confirme que sua API key tem créditos/quota disponível
- Tente trocar de provedor

### **"Resposta muito lenta"**
- Modelos maiores (GPT-4, Claude Opus) são mais lentos
- Tente usar modelos mais rápidos (GPT-3.5, Gemini Flash)
- Verifique sua conexão de internet
